# genesis-trade
un APP di trading scritta in python

## descizione
questo progetto simula un mercato di 4 crypto usando il GBM (Geometric Brownian Motion) 

## funzionalità
* gestisce piu utenti
* gestisce portafoglio e carta d credito
* simula l'andamento del mercato tramite GBM

## per installazione
per installarlo useguire il codice bash
pip install -r requirements.txt
